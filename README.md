# 🛍️ AI Shopping Assistant

An AI-powered shopping assistant that helps users find relevant products using semantic search.

## 🚀 Features

- Upload a product catalogue using CSV
- AI-powered product matching
- Semantic search using Sentence Transformers
- Finds the most relevant products based on user queries
- Displays the top 5 recommended products
- Simple and user-friendly Streamlit interface

## 🧠 Technologies Used

- Python 3.12
- Streamlit
- Pandas
- Sentence Transformers
- Python-dotenv
- Requests
- Pydantic
